# デザインシステムを一から作ってみた話

個人プロジェクトで、いつも場当たり的に CSS を書いていました。プロジェクトが大きくなるにつれて管理しきれなくなったので、ちゃんとしたデザインシステムを作ることにしました。

## なぜデザインシステムが必要か

デザインシステムがないと、こんな問題が起きます：

- ボタンのスタイルがコンポーネントごとにバラバラ
- 色の数値があちこちに散らばってコピペミスが起きる
- 「このパディングいくつだっけ？」と悩む時間が増える
- ダークモード対応が地獄になる

## CSS カスタムプロパティでトークンを定義する

デザインシステムの核心は **デザイントークン** です。色・スペーシング・フォントサイズなどを変数として定義します。

```css
:root {
  /* カラーパレット */
  --color-primary: #A8D8D8;
  --color-secondary: #F6C1D1;
  --color-accent: #C8BFEE;

  /* テキスト */
  --text-primary: #1A2C30;
  --text-muted: #8A9A9C;

  /* スペーシング (4px基準) */
  --sp-xs: 0.25rem;   /* 4px  */
  --sp-sm: 0.5rem;    /* 8px  */
  --sp-md: 1rem;      /* 16px */
  --sp-lg: 1.5rem;    /* 24px */
  --sp-xl: 2rem;      /* 32px */

  /* 角丸 */
  --radius-sm: 6px;
  --radius-md: 12px;
  --radius-full: 9999px;
}
```

## ダークモードの対応

ダークモードは `:root` と同じトークン名で値を上書きするだけです。

```css
[data-theme="dark"] {
  --text-primary: #FFF9F4;
  --text-muted:   #8A9A9C;
}
```

コンポーネント側は `var(--text-primary)` を使うだけでいい。

## まとめ

デザインシステムを作ってから、CSS を書くのが楽しくなりました。最初は面倒に感じますが、長期的には開発速度が上がります。
